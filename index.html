Web application

AQI Monitoring Web Application

ReactJavaScript CSSREST API

A real-time air quality dashboard on a public REST API, rendering current AQI, a pollutant breakdown and historical trends. One number drives the whole interface: the band it falls into decides the colour, the advice, the threshold line and whether an alert is raised.

Station

Response

Conditional band styling

Drag the hour scrubber and one value redraws everything: reading, band, advice, pollutant bars and the alert. That cascade is the actual logic of the project.

Threshold alerting

Cross AQI 100 on any station and the alert appears on its own, rather than leaving the viewer to interpret the number.

Graceful degradation

Skeletons while the request is in flight and an explicit retry on failure, so a dead API still produces a usable screen. Tested in Chrome, Firefox and Edge.
